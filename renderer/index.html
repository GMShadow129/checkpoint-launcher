Configurar CurseForge

Para buscar mods en CurseForge necesitás una API key gratuita y personal.

¿Cómo conseguir tu key?

  1. Andá a console.curseforge.com (se abre en una nueva pestaña)
  2. Creá una cuenta gratis si no tenés
  3. Click en API Keys → Generate New Key
  4. Copiala (empieza con $2a$10$)
  5. Pegala abajo y dale a Validar

🔒 Se guarda solo en tu PC, nunca se envía a ningún servidor nuestro.
